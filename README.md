# 💸 ExpenseNoti — ระบบแจ้งเตือนค่าใช้จ่ายรายเดือนผ่าน LINE

เว็บแอปเล็ก ๆ ไว้จัดการค่าใช้จ่ายประจำเดือน (ค่าน้ำ ค่าไฟ ผ่อนบ้าน ผ่อนรถ ผ่อนสินค้า ฯลฯ)
แล้วส่งแจ้งเตือนเข้า **LINE** อัตโนมัติ — สรุปรวมรายเดือน, เตือนก่อนถึงกำหนด, เตือนวันครบกำหนด และนับงวดผ่อนที่เหลือ

> ⚠️ **หมายเหตุสำคัญ:** LINE Notify ปิดบริการไปแล้วตั้งแต่ **1 เมษายน 2025**
> ระบบนี้จึงใช้ **LINE Messaging API** ซึ่งเป็นตัวที่ LINE แนะนำให้ใช้แทน (ส่งข้อความ push ฟรีได้จำนวนหนึ่งต่อเดือน)

---

## คุณสมบัติ

- หน้าจอเว็บสำหรับ **เพิ่ม / แก้ไข / ลบ** รายการค่าใช้จ่าย
- เก็บข้อมูลในเครื่องด้วย **SQLite** (ไฟล์ `expenses.db`)
- รองรับทั้งค่าใช้จ่าย **รายเดือนไม่จำกัด** (ค่าน้ำ ค่าไฟ) และ **การผ่อนเป็นงวด** (นับงวดที่เหลือให้)
- การแจ้งเตือน 4 แบบ:
  - 📊 **สรุปรวมรายเดือน** — รวมทุกรายการ + ยอดรวมทั้งเดือน
  - 🔔 **เตือนก่อนถึงกำหนด** — ตั้งได้ว่ากี่วันล่วงหน้าต่อรายการ
  - ⏰ **เตือนวันครบกำหนด**
  - 🧮 **นับงวดผ่อน** — แสดงงวดที่ X/Y และเหลืออีกกี่งวด ผ่อนครบแล้วหยุดเตือนเอง
- ปุ่ม **"จ่ายแล้ว +1"** เพื่อบันทึกเมื่อจ่ายงวดนั้นแล้ว
- กันส่งซ้ำในวันเดียวกัน (เก็บประวัติใน `notify_log`)

## วิธีติดตั้งและใช้งาน

### 1) ติดตั้ง Python และไลบรารี
ต้องมี Python 3.9 ขึ้นไป

```bash
cd ExpenseNoti
pip install -r requirements.txt
```

### 2) ตั้งค่า LINE Messaging API
1. เข้า https://developers.line.biz/console/ แล้วล็อกอินด้วยบัญชี LINE
2. สร้าง **Provider** → สร้าง **Messaging API channel**
3. ในแท็บ **Messaging API** กดออก **Channel access token (long-lived)** แล้วคัดลอกไว้
4. ใช้มือถือ **เพิ่มบอทเป็นเพื่อน** (สแกน QR ในหน้า channel)
5. หา **User ID** ของคุณ (ขึ้นต้นด้วยตัว `U`) — ดูได้จากแท็บ Basic settings ของ channel ("Your user ID") หรือจาก webhook

จากนั้นสร้างไฟล์ตั้งค่า:

```bash
cp .env.example .env
```

แล้วแก้ `.env` ใส่ค่า:

```
LINE_CHANNEL_ACCESS_TOKEN=<token ที่คัดลอกมา>
LINE_TO_USER_ID=<User ID ของคุณ เริ่มด้วย U>
```

### 3) เปิดเว็บจัดการ

```bash
python3 app.py
```

เปิดเบราว์เซอร์ไปที่ http://localhost:5000 แล้วเพิ่มรายการค่าใช้จ่ายได้เลย
ลองกด **"ส่งสรุปทดสอบเข้า LINE"** เพื่อเช็คว่าตั้งค่าถูก

> ค่าน้ำ/ค่าไฟ: เว้นช่อง "จำนวนงวดทั้งหมด" ว่างไว้ (เป็นรายเดือนไม่จำกัด)
> การผ่อน: ใส่จำนวนงวดทั้งหมด + จ่ายไปแล้วกี่งวด ระบบจะนับให้

### 4) ตั้งเวลาส่งอัตโนมัติทุกวัน

ดูตัวอย่างข้อความก่อนได้โดยไม่ส่งจริง:

```bash
python3 scheduler.py --dry-run
```

ตั้ง cron ให้รันทุกวัน 8 โมงเช้า (macOS / Linux — พิมพ์ `crontab -e`):

```cron
0 8 * * *  cd /path/to/ExpenseNoti && /usr/bin/python3 scheduler.py >> cron.log 2>&1
```

- สรุปรวมรายเดือนจะส่ง **วันที่ 1 ของเดือน** (เปลี่ยนได้ด้วย `--summary-day N`)
- เตือนก่อน/ถึงกำหนดจะเช็คให้ทุกวันตามที่ตั้งไว้ในแต่ละรายการ

## ฟังก์ชันที่เพิ่มได้ในอนาคต (โครงรองรับไว้แล้ว)

- รองรับผู้ใช้/ผู้รับหลายคน (ตาราง users + ส่ง multicast)
- แนบ Flex Message สวย ๆ แทนข้อความธรรมดา
- กราฟสรุปค่าใช้จ่ายย้อนหลัง (ตาราง notify_log มีข้อมูลเริ่มต้นแล้ว)
- แจ้งเตือนเมื่อผ่อนใกล้ครบ / ครบงวดสุดท้าย
- ตั้งงบประมาณรายเดือนและเตือนเมื่อเกิน
